Install

  1. Rider 2026.2 or later, with the .NET 10 SDK on the PATH Rider loads from your shell.
  2. Settings → Plugins → Marketplace → Diff Graph → Install, or install the zip from a release through ⚙ → Install Plugin from Disk.
  3. Open the tool window: View → Tool Windows → Diff Graph, or Ctrl+Shift+Alt+G.

How it works

Each side of the change is checked out into a temporary worktree, the solution is restored and loaded by Roslyn, and a symbol graph is built per side: the types in the repository and the dependencies between them. The two graphs are compared and the difference is drawn. A side's graph is cached by content, so an unchanged working tree is read from the cache. Only the projects holding changed files are compiled.

Limits

  • C# only. Other changed files are listed with their hunks but have no node.
  • A dependency Roslyn cannot resolve (a package that did not restore, generated code not on disk) is missing from the graph.
  • Both sides must load: a commit that does not restore gives no graph.
